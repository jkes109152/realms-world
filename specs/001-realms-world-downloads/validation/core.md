# 最小共用核心驗證

**日期**：2026-09-14

**範圍**：T006～T023。本紀錄只涵蓋本機共用核心；G0 真實平台、Realms 與遊戲匯入尚未通過。

## 實作與驗證

- 已建立 13 張 D1 資料表、索引、CHECK／外鍵及初始前向遷移；本機遷移追蹤避免重複套用。
- 已建立唯一管理員、固定成本 scrypt、一次性維護 batch、條件 session、Origin／CSRF、D1 原子限流及 AES-256-GCM 加密封裝。
- Microsoft 裝置碼、Xbox 簽章／XSTS 與刷新以跨請求加密狀態及短租約推進；取消、session 失效與解除後拒絕晚到結果。
- Realms 僅投影擁有者資料；尚無真實映射證據的欄位與歷史維持拒絕。未填猜測 Client-Version、來源主機或 redirect 規則。
- 下載工作與請求觀察同批建立；最多 20 次準備、一次強制續期、60 秒單次票據與最後發布版本檢查。串流前檢查來源及 ZIP 前綴，維持背壓；不整檔緩衝或保存世界。
- 固定白名單的管理員驗證頁與 API 已接上相同核心；公開下載保持 503。完整來源列表中消失的欄位會下架，並清除舊票及加密描述。

| WebMCP | read_verification_status 已註冊；空物件回安全摘要，額外欄位明確拒絕；不傳回帳號、代碼、token 或票據 |

初始 T010～T012 測試在核心模組尚未存在時失敗，再完成實作。首次串流測試辨識 Workers 不接受 redirect:error，已改為 manual 並明確拒絕非允許跳轉；之後新增的回歸案例亦通過。沒有宣稱每個後加斷言都曾個別失敗。

D1 案例包含同票 20 次並行最多一次兌換、下架再發布舊票拒絕、附件開始前下架競爭、20 次準備上限、解除後晚到刷新、過時 reset 整批回滾，以及提交後回應遺失僅讀回證據而不重播維護寫入。
