# 最小共用核心驗證

**日期**：2026-09-14

**範圍**：T006～T023。本紀錄只涵蓋本機共用核心；G0 真實平台、Realms 與遊戲匯入尚未通過。

## 實作與驗證

- 已建立 13 張 D1 資料表、索引、CHECK／外鍵及初始前向遷移；本機遷移追蹤避免重複套用。
- 已建立唯一管理員、固定成本 scrypt、一次性維護 batch、條件 session、Origin／CSRF、D1 原子限流及 AES-256-GCM 加密封裝。
- Microsoft 裝置碼、Xbox 簽章／XSTS 與刷新以跨請求加密狀態及短租約推進；取消、session 失效與解除後拒絕晚到結果。
- Realms 僅投影擁有者資料；尚無真實映射證據的欄位與歷史維持拒絕。未填猜測 Client-Version、來源主機或 redirect 規則。
- 下載工作與請求觀察同批建立；最多 20 次準備、一次強制續期、60 秒單次票據與最後發布版本檢查。串流前檢查來源及 ZIP 前綴，維持背壓；不整檔緩衝或保存世界。
- 固定白名單的管理員驗證頁與 API 已接上相同核心；公開下載保持 503。完整來源列表中消失的欄位會下架，並清除舊票及加密描述。

初始 T010～T012 測試在核心模組尚未存在時失敗，再完成實作。首次串流測試辨識 Workers 不接受 redirect:error，已改為 manual 並明確拒絕非允許跳轉；之後新增的回歸案例亦通過。沒有宣稱每個後加斷言都曾個別失敗。

D1 案例包含同票 20 次並行最多一次兌換、下架再發布舊票拒絕、附件開始前下架競爭、20 次準備上限、解除後晚到刷新、過時 reset 整批回滾，以及提交後回應遺失僅讀回證據而不重播維護寫入。

## 尚未執行

T024～T030 的 hosted D1／資源量測、真實 Microsoft 授權及續期、兩欄位與非作用中欄位歷史映射、最新／歷史／最大世界下載、基岩版匯入、三個各 1 GiB hosted 串流與 hosted 競爭驗證，均不得由以上本機結果代替。尚未開始 T031 之後的完整故事。

上述為本機核心完成時的範圍。後續 T024 的部分真實結果記錄於 [G0 平台實測](g0-platform.md)，G0 仍未通過；授權階段新增的回歸與修正見 [真實授權紀錄](g0-auth.md)，目前合計 68 項本機測試通過。


新增最新發布回歸：固定 owner／slot／latest 路由，不讀歷史；擁有者不符、未核對主機或官方準備中均維持私有且無工作／票據。latest 發布後歷史工作仍拒絕。既有並行準備測試的人工歸屬證據已與欄位身分一致，保留原 20 次上限斷言。


授權續期新增 6 項回歸，世界讀取只接續 authorization_refreshing，遵守間隔／取消／上限，一般錯誤不重送；D1 等待續期保留發布版本與世代。真實續期及畫面恢復證據見 [授權驗證](g0-auth.md)。

## 首頁與最新下載子集

新增 3 項公開 API 整合案例，目前 11 個檔案共 68 項通過；補充後的公開與管理驗證入口 9 項相關案例亦通過。涵蓋安全投影、兩個新下載工作各自請求官方 latest、不重用前次描述、capability／下架失效、歷史與任意 URL 拒絕，以及關閉後列表／建立／step／status／兌換均拒絕。管理 catalog 對匿名與失效 session 回 401，額外參數回 400。

首頁只在公開路由明確 downloads_closed 且管理員 session 有效時進入驗證預覽。未登入關閉、確實空清單、服務錯誤分別呈現；所有檔案仍以單次票據及原生表單串流。使用者尚未匯入，這些人工案例與首頁預覽不代表正式匿名開放或完整 US1 通過。

本次 TypeScript、ESLint 與 Sites 五階段生產建置通過。私人部署後首頁原生下載實際取得 11,402,793 bytes，使用者裝置檔案與伺服器觀察相等；版本、時間、雜湊及匯入待完成狀態見 [首頁實測](g0-downloads.md)。
