# 功能規格： Realms World 公開世界下載站

**功能分支**： `001-realms-world-downloads`

**建立日期**： 2026-09-13

**狀態**：需求品質檢查、技術設計、任務清單與文件一致性分析完成；實作、串接與發布驗證尚未執行。分析結果見[分析紀錄](checklists/analysis.md)。

**需求來源**：使用者描述：「根據剛剛的方案啟動 SDD」。
建立單一管理員經營的基岩版 Realms 公開下載站；管理員使用自製帳號密碼登入，
連接自己擁有的 Realms，逐一開放世界欄位。匿名訪客可下載已開放世界的最新及所有可用歷史存檔。
第一版只提供手動下載到訪客裝置，不保存世界檔，不執行定時備份。

## 使用者情境與驗收

### 使用者故事 1 - 訪客下載公開世界的最新存檔 （優先級： P1）

訪客開啟網站，選擇已公開的世界，不需登入網站、Microsoft 或 ChatGPT，
即可下載官方當時提供的最新存檔，並在自己的基岩版遊戲匯入。

**優先理由**： 這是網站的核心用途，讓玩家直接取得擁有者願意分享的世界。

**獨立驗證**： 預先準備一個已發布世界與可下載存檔，以全新匿名瀏覽狀態走完列表、
選擇世界與下載；不依賴管理後台畫面即可驗證此流程。

**驗收情境**：

1. **前提** 至少一個世界已發布且連線有效，**當** 匿名訪客開啟首頁，
   **則** 只看見已發布世界及下載入口，無任何登入要求。（FR-001、FR-002）
2. **前提** 訪客開啟已發布世界，**當** 查看世界資料，
   **則** 顯示名稱、說明及來源可提供的存檔時間、大小、遊戲版本；缺少資料時標示未提供，
   不捏造數值。（FR-003、FR-004）
3. **前提** 官方最新可下載存檔存在，**當** 訪客選擇下載最新存檔，
   **則** 取得對應世界的完整 `.mcworld`，檔案可匯入相容的基岩版遊戲。（FR-005）
4. **前提** 網站尚未發布任何世界，**當** 訪客開啟首頁，
   **則** 看見「目前沒有開放下載的世界」，而非示範世界或錯誤頁。（FR-002）
5. **前提** 網站正在取得存檔或官方服務無法回應，**當** 訪客開始下載，
   **則** 看見準備中或可理解的不可用原因及重試方式，不會拿到被當作世界檔的錯誤內容。
   （FR-022、FR-023）
6. **前提** 多位訪客下載可用的大型世界，**當** 傳輸期間重新整理網站，
   **則** 其他頁面仍可操作，網站沒有保留一份可供日後重複下載的世界副本。（FR-007、FR-024）

### 使用者故事 2 - 管理員登入並連接自己的 Realms （優先級： P1）

唯一管理員使用網站自己的帳號密碼登入後台，透過 Microsoft 的授權頁面連接帳號。
網站記住授權，管理員下次回來能繼續使用，也可隨時解除連線。

**優先理由**： 必須先建立真實擁有者連線與後台保護，才能授權公開下載。

**獨立驗證**： 使用預先建立的管理員帳號及可控制的授權狀態，
獨立驗證登入、改密碼、連接、續期與解除流程；不必發布任何世界。

**驗收情境**：

1. **前提** 管理員帳號已經建立，**當** 輸入正確或錯誤帳密，
   **則** 正確帳密可進入後台，錯誤帳密只收到一般登入失敗訊息，不能建立第二個管理員。
   （FR-008、FR-009、FR-021）
2. **前提** 管理員已登入，**當** 登出、工作階段失效或修改密碼，
   **則** 登出或失效的工作階段不能再操作；修改密碼須驗證目前密碼，
   舊密碼及所有原有工作階段均失效，管理員以新密碼重新登入。（FR-008、FR-010）
3. **前提** 管理員忘記密碼，**當** 執行受保護的維護重設流程，
   **則** 可恢復自己的帳號；匿名訪客不能利用該流程取得管理權限。（FR-009）
4. **前提** 尚未連接 Microsoft 帳號，**當** 管理員選擇連接，
   **則** 由 Microsoft 授權頁面完成身分確認，本站不要求輸入 Microsoft 密碼；
   拒絕、取消或逾時均不產生可用連線。（FR-011）
5. **前提** 連線有效，**當** 管理員再次登入網站或授權需要續期，
   **則** 網站可使用保存的授權繼續取得資料；續期失敗時顯示需重新連接，
   並停止新的下載，不宣稱連線正常。（FR-012、FR-013）
6. **前提** 已連接擁有者帳號，**當** 查看 Realms，
   **則** 列出該帳號擁有的 Realm 與世界欄位；受邀加入但不擁有的 Realm 不能被發布。
   （FR-014）
7. **前提** 有已發布世界，**當** 管理員解除 Microsoft 連線，
   **則** 保存的授權被刪除，所有世界下架，新的下載被拒絕；再次連線仍須逐一重新發布。
   （FR-015）

### 使用者故事 3 - 管理員選擇公開世界並隨時下架 （優先級： P1）

管理員查看自己擁有的 Realm 和世界欄位，選擇要分享的欄位，
設定網站上顯示的名稱與說明，並明確發布或下架。

**優先理由**： 「可自由下載」只適用於擁有者選擇分享的內容，不能意外公開所有世界。

**獨立驗證**： 準備同一 Realm 的兩個不同欄位及另一個未發布 Realm，
獨立操作發布設定並檢查公開結果及拒絕行為。

**驗收情境**：

1. **前提** 首次連線或新發現的世界欄位，**當** 管理員查看世界清單，
   **則** 每個欄位預設不公開，訪客無法取得其詳細資料與檔案。（FR-016、FR-019）
2. **前提** 管理員選擇一個可確認存檔歸屬的世界欄位，**當** 發布該欄位，
   **則** 系統說明會公開最新及所有可用歷史存檔，發布後只開放該欄位，
   不連帶公開同 Realm 的其他欄位。（FR-016、FR-017、FR-019）
3. **前提** 世界已發布，**當** 管理員修改顯示名稱或說明，
   **則** 公開頁面反映變更，但 Realms 內的世界名稱及內容不被更改。（FR-017）
4. **前提** 訪客持有舊列表或下載入口，**當** 管理員下架世界後訪客再請求下載，
   **則** 新請求被拒絕，即使舊畫面仍顯示下載按鈕；已經開始的傳輸不保證中止。
   （FR-018）
5. **前提** 訪客更換世界、欄位或存檔識別資料，**當** 嘗試取得未公開或歸屬不明的內容，
   **則** 被拒絕且不洩露該內容的存在與詳細資訊，也不能藉此操作管理功能。（FR-019、FR-020）
6. **前提** 同一欄位的官方最新存檔更新，**當** 訪客重新取得最新資料或發起新下載，
   **則** 對應新的可用存檔；管理員若保持該欄位公開，新的可用歷史存檔也納入公開範圍。
   （FR-004、FR-016）

### 使用者故事 4 - 訪客選擇歷史存檔下載 （優先級： P2）

訪客在公開世界頁面查看官方仍保留的歷史存檔，依時間選擇需要的版本下載，
了解這些版本可能隨官方保存政策而消失。

**優先理由**： 在最新下載之外提供回顧或取得舊世界的能力，且不誤導訪客以為網站永久備份。

**獨立驗證**： 準備同一公開世界的多份存檔，包含缺少部分資料及已失效的存檔，
驗證排序、選取與失效處理；不依賴修改管理員帳號。

**驗收情境**：

1. **前提** 公開世界有多份可用歷史存檔，**當** 訪客開啟歷史列表，
   **則** 依存檔時間由新到舊排列，可查看所有官方目前提供且歸屬已確認的項目。
   （FR-003、FR-006）
2. **前提** 訪客選取指定歷史存檔，**當** 開始下載，
   **則** 下載的是該份存檔，不會在失效時悄悄改成最新或其他欄位的版本。（FR-006、FR-019）
3. **前提** 存檔曾出現在列表但已被官方移除，**當** 訪客下載或重新整理，
   **則** 得知該份已不可用，可以重新取得可用列表，不會被承諾稍後必定恢復。（FR-022）
4. **前提** 官方無歷史存檔或欄位對應無法確認，**當** 訪客開啟歷史列表，
   **則** 顯示沒有可用歷史存檔或暫時無法確認，不以其他世界存檔填補。（FR-006、FR-019）

### 使用者故事 5 - 管理員理解下載結果與服務狀態 （優先級： P2）

管理員查看最近操作與下載紀錄，區分請求、傳輸結果與需要處理的連線問題，
不依賴訪客聲稱完成下載來判定伺服器傳輸結果。

**優先理由**： 公開站的下載依賴外部服務，管理員需要知道問題發生在哪個世界及何時發生。

**獨立驗證**： 預先建立已請求、傳輸結束、失敗及結果不明的紀錄，
驗證管理員能辨認狀態，匿名訪客不能閱讀管理紀錄。

**驗收情境**：

1. **前提** 發生連接、解除連線、發布、下架或下載請求，**當** 管理員查看紀錄，
   **則** 可看見發生時間、操作類別、適用的世界／存檔及結果。（FR-025）
2. **前提** 傳輸結束、連線中斷或結果無法確認，**當** 查看下載紀錄，
   **則** 分別呈現傳輸結束、已確認失敗或結果不明，不宣稱檔案已存入訪客裝置或成功匯入。
   （FR-026）
3. **前提** 發生授權或下載錯誤，**當** 查看公開訊息或管理紀錄，
   **則** 有可理解的原因與下一步，不含密碼、Microsoft 權杖、下載授權或原始敏感錯誤內容。
   （FR-020、FR-022）
4. **前提** 紀錄跨日或超過保存期間，**當** 查看紀錄，
   **則** 日期與時間以台灣時區顯示，僅可查閱最近 30 天的紀錄。（FR-025、FR-027）

### 邊界情況

- 連接成功但沒有擁有的 Realm：顯示空狀態，不把受邀 Realm 當成可管理世界。
- Realm 到期、停用或擁有者權限改變：以官方實際可讀取／下載結果判定，不僅憑到期標記判定不可用。
- 存檔列表與下載請求之間產生新存檔：指定歷史下載保持原選擇，最新下載以官方當時可提供者為準。
- 同一 Realm 有多個欄位、空欄位或被替換的世界：不假設存檔列表一定按欄位隔離；
  無法確認歸屬時拒絕公開該項，提示管理員處理。
- 下架、解除連線與下載同時發生：狀態變更生效後拒絕新的下載；
  已開始的傳輸與訪客已取得的檔案不保證可撤回。
- 授權被撤回、續期失敗或取消登入：停止依賴失效授權的新下載，顯示需重新連接；不無限重試。
- 官方暫時限流、準備檔案或服務不可用：顯示目前狀態與可重試時機，不能反覆自動建立重複下載。
- 準備期限已過但檔案正在傳輸：不取消已開始的附件；在觀察有效期間仍可查詢，查詢失效不表示檔案傳輸失敗。
- 工作的下載授權到期：先清除短期秘密，不連帶刪除仍在最近 30 天範圍內的下載紀錄。
- 重設密碼與另一個帳號變更同時發生：過時重設被拒絕，不覆寫較新密碼或使較新登入意外失效。
- 檔案大小／時間／版本缺失：清楚標示未提供，不能以 0 或當前時間代替未知值。
- 網路中斷、磁碟空間不足或瀏覽器關閉：不將無法確認的結果算成匯入成功；
  第一版可重新發起完整下載，不承諾斷點續傳或自動匯入。
- 長名稱、中文名稱與重複存檔名稱：顯示與下載檔名仍可辨識世界及版本，不破壞裝置正常儲存。
- 完全無資料、外部服務不可用與登入失敗必須區別呈現；不得顯示假資料掩蓋未完成串接。

## 需求

### 功能需求

#### 公開瀏覽與下載

- **FR-001**: 網站必須在 `https://realms.jkesbyebye.com` 提供匿名瀏覽及下載，
  不要求訪客擁有網站、Microsoft 或 ChatGPT 帳號。
- **FR-002**: 公開列表必須僅包含已發布世界；提供載入中、尚未發布任何世界及服務不可用的不同狀態。
- **FR-003**: 世界頁必須顯示公開名稱、說明及來源可提供的存檔時間、大小、遊戲版本；
  未知資訊明確標示未提供，不推測值。
- **FR-004**: 「最新存檔」必須表示官方當時提供的最新可下載版本；
  不宣稱包含尚未保存的進度，頁面必須顯示資料取得時間。
- **FR-005**: 訪客必須能下載已發布世界的最新存檔為可匯入相容基岩版的 `.mcworld`，
  並使用可辨識世界及存檔版本的安全檔名。
- **FR-006**: 訪客必須能依新到舊查看及選擇已發布世界全部可用歷史存檔；
  選定歷史版本不得被自動替換成其他版本。
- **FR-007**: 世界檔必須只因使用者手動下載而被轉送到其裝置；
  網站不保留可重用的世界檔副本，不提供排程或官方存檔消失後的離線副本。

#### 管理員帳號與 Realms 連線

- **FR-008**: 網站必須提供唯一管理員的自製帳號密碼登入、登出及登入失效處理；
  未登入或失效工作階段不能執行任何管理操作。
- **FR-009**: 管理員初始建立及忘記密碼重設必須透過受保護的維護流程完成，
  不提供公開註冊、第二管理員或匿名取得管理權限的方式。
- **FR-010**: 已登入管理員必須能驗證目前密碼後修改密碼；
  修改或維護重設成功後，舊密碼與所有原有登入工作階段失效。
- **FR-011**: 管理員必須能在 Microsoft 的授權頁面完成 Realms 帳號連接；
  本站不收集 Microsoft 密碼，並能處理取消、拒絕與授權逾時。
- **FR-012**: 網站必須記住已成功連接的 Microsoft 授權，
  讓管理員下次登入及未開啟後台時的訪客下載可重用有效連線；保存資料不能以明文秘密暴露。
- **FR-013**: 授權續期失敗或被撤回時，網站必須停止新的下載並告知管理員需要重新連接；
  訪客僅看見世界暫時無法下載，不取得帳號或授權詳情。
- **FR-014**: 管理員必須能查看所連帳號擁有的 Realm 及世界欄位，
  並辨識空欄位與不可用項目；不能發布僅受邀加入的 Realm。
- **FR-015**: 管理員必須能解除連線；完成後網站刪除該連線的保存授權、
  下架其全部世界並停止新的下載，重新連接不自動重新發布。
  本站不宣稱解除連線等於撤銷 Microsoft 帳號在其他應用程式的授權。

#### 發布與權限邊界

- **FR-016**: 每個新發現或重新連接的世界欄位必須預設不公開；
  管理員逐一明確發布後，該欄位的最新及所有可用歷史存檔才會一併公開。
- **FR-017**: 管理員必須能設定世界的網站顯示名稱、說明及發布狀態；
  發布前清楚說明歷史存檔也會公開，顯示設定不得改動 Realms 內世界。
- **FR-018**: 下架或解除連線生效後，網站必須拒絕新下載，即使請求來自舊畫面或先前取得的下載入口；
  不承諾中止已開始的傳輸或收回已下載檔案。
- **FR-019**: 網站必須在提供世界資料及每次新下載時驗證發布狀態和世界／欄位／存檔歸屬，
  拒絕越權與歸屬不明的內容，且不洩露未公開內容的存在與細節。
- **FR-020**: 管理功能必須僅允許有效管理員操作；
  公開頁面、下載結果及一般紀錄不得含帳密、授權秘密、未公開世界資料或不必要的帳號／成員資訊。

#### 可靠性、紀錄與使用體驗

- **FR-021**: 網站必須限制重複失敗登入與過量下載請求；
  達到可設定的門檻時拒絕新嘗試並顯示何時可重試，不影響已合法開始的傳輸。
- **FR-022**: 網站必須區分存檔已移除、世界已下架、連線需要恢復、服務暫時不可用及下載準備中；
  依情況提供重試或重新整理入口，且不以敏感的原始錯誤內容取代使用者訊息。
  管理員可查看實際原因；對未知或未公開世界識別的公開請求採一致的不可用回應，
  不藉由錯誤差異洩露未公開內容是否存在。
- **FR-023**: 下載準備與傳輸過程必須不把失敗內容當作有效世界檔；
  開始前失敗明確提示，開始後中斷不能記成已確認成功傳輸，也不自動換版重送。
- **FR-024**: 網站必須支援未知大小與大型世界下載，不要求先載入完整世界檔才能開始儲存，
  並在正常並行下載負載下維持公開頁面與後台可操作。
- **FR-025**: 管理員必須能查閱最近 30 天的連接、解除連線、發布、下架及下載紀錄；
  每筆含時間、類別、適用的世界／存檔及可確認的結果；超過保存期間的紀錄不再可查閱並予以清理。
- **FR-026**: 紀錄必須區分下載請求、伺服器傳輸結束、已確認的失敗與結果不明；
  傳輸結束不等於訪客成功儲存或匯入，訪客回報不能單獨作為傳輸成功依據。
- **FR-027**: 網站必須提供繁體中文、台灣時區標示及手機／電腦可用的操作介面；
  主要功能可用鍵盤操作，在 360 與 1440 像素寬度及文字放大 200% 下仍可辨識與操作。

### 核心實體

- **管理員**：唯一可管理本站的帳號；具有網站登入資訊與可失效的登入狀態，與 Microsoft 帳號分開。
- **Microsoft 連線**：管理員授權使用的一個擁有者帳號，含身分關聯、連線狀態、
  可重用授權及有效性；解除後不得繼續提供下載。
- **Realm**：連接帳號所擁有的官方世界託管單位，可含多個世界欄位及不同可用狀態。
- **世界欄位與發布設定**：可逐一開放的單位，關聯 Realm、欄位、公開名稱、說明與發布狀態。
- **可下載存檔**：官方目前提供的世界版本，關聯正確世界欄位、來源識別、時間及可選的大小／版本；
  網站不持有其持久檔案副本。
- **操作與下載紀錄**：有保存期限的操作事件與傳輸觀察結果，不代表訪客端成功保存或匯入。

## 成功標準

### 可量測成果

- **SC-001**: 在已發布且可用的測試世界上，匿名訪客從首頁起最多 3 次主要操作即可發起最新下載，
  全程不需登入；20 次驗收操作均取得所選世界，而非其他世界。
- **SC-002**: 至少完成一份最新及一份不同的歷史存檔真實下載，
  其中至少一份成功匯入相容的基岩版遊戲；測試明確記錄世界、版本、檔案大小及結果。
- **SC-003**: 管理員首次連接後，在一次新的網站登入與至少一次授權續期驗收中仍能取得 Realms；
  取消授權、續期失敗與解除連線情境均正確停止新下載。
- **SC-004**: 未登入管理操作、跨世界／欄位存取、下架後使用舊入口、
  解除連線後下載與失效工作階段的驗收案例全部被拒絕，且未公開內容與授權秘密外洩次數為 0。
- **SC-005**: 在外部服務正常回應、穩定連線的驗收條件下，20 次列表與世界頁瀏覽至少 19 次
  在 5 秒內呈現可操作內容；下載請求在 2 秒內提供可見回饋，不承諾官方準備檔案或完整下載時限。
- **SC-006**: 3 個同時進行、各至少 1 GiB 的模擬世界下載可完整完成，
  同時進行的 20 次頁面瀏覽均可操作，沒有因整個世界檔載入而失敗；
  另以實際最大世界完成一次真實下載並記錄大小，不能用模擬結果替代真實串接。
- **SC-007**: 存檔消失、官方限流、授權失效、下載中斷及無世界可用的情境，
  100% 顯示對應狀態與合理下一步，且不顯示假資料或虛假的完成結果。
- **SC-008**: 登入、連接、發布、下架、最新與歷史下載等主要流程，
  在 360 與 1440 像素寬度、鍵盤操作及文字放大 200% 的驗收中皆可完成。
- **SC-009**: 真實傳輸結束、已確認失敗及無法確認結果的測試紀錄均正確標示，
  管理員可查閱最近 30 天資料，不能查閱過期資料；任何紀錄都不宣稱使用者已成功匯入。
- **SC-010**: 正式網域可透過加密連線使用，匿名下載與管理員登入互相獨立；
  只有通過真實連線、下載、權限與錯誤處理驗收後，才視為可公開運作。
  部署前先通過可在驗證環境完成的功能與安全驗收；正式網域部分在部署、DNS 與憑證就緒後驗證，
  不因前置檢查通過而提前標示正式入口已驗收。

## 假設與依賴

### 已確認的範圍

- 管理員就是要串接的 Realm 擁有者；第一版只有一個網站管理員及一個 Microsoft 連線，
  但可管理該帳號下多個 Realm 與世界欄位。
- 「最高權限」指完整管理本站帳號、連線、發布與紀錄；不新增遊戲服務未授予的權限。
- 世界以欄位為發布單位；開放後該欄位未來新增、仍可取得的存檔也公開，直到管理員下架。
- 解除連線會清除本站授權並下架世界；單純登出網站不解除 Microsoft 連線，
  因此已公開世界仍可在有效授權下提供訪客下載。
- 網站只保存必要設定、連線資料與操作紀錄；不保存世界檔，不保證官方已移除存檔可再次下載。
- 不包含公開註冊、多管理員、一般會員、定時備份、雲端世界保存、上傳替換、
  世界還原、Realm 開關、成員管理、斷點續傳或自動匯入遊戲。

### 合理預設

- 網站名稱為 Realms World，公開語言為繁體中文，日期時間顯示台灣時區。
- 操作紀錄保留最近 30 天，第一版不提供訪客個人下載帳戶或訪客個資分析。
- 初始驗收負載為 3 個並行下載；使用 1 GiB 模擬檔驗證大型傳輸，
  此數值不是世界大小上限，也不代表已知實際世界大小。
- 更換 Microsoft 帳號須先解除既有連線；新連線下所有世界重新設定發布狀態。
- 顯示名稱與說明僅作為網站資訊；空白說明可以不顯示，不修改官方世界資料。

### 依賴與驗證前提

- 官方授權、擁有者權限、世界欄位與歷史存檔下載的可用性，均須在正式執行環境實測，
  規格完成不表示這些能力已驗證。
- 真實串接驗收需要管理員親自完成 Microsoft 授權；網站不得以保存其密碼代替授權。
- 真實驗收需至少一個可用世界及一份不同的歷史存檔；若官方尚未提供必要資料，
  相應驗收保持未完成，不製造假成功結果。
- 實際最大世界大小目前未知，須在串接驗證時讀取或測量，不以猜測值規劃容量。
- 官方存檔保存期限可能改變；網站以實際可用性為準，不把目前保存政策寫成永久承諾。
- 正式網域與網站託管屬既定交付約束；技術規劃須承接專案憲章與本功能的 planning-input.md，
  該交接文件保留前期選擇，正式設計以 plan.md 及其關聯文件為準。
